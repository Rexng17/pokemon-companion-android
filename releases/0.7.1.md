# 0.7.1 · 无广告试用版 / Ad-free trial

下载 **`pokemon-companion-0.7.1.apk`** 安装，最低 Android 8.0。大小 3,698,879 字节（约 3.7 MB）。沿用原签名，版本号已增加，可覆盖安装此前的 0.7.0，无需卸载。

## 本次变化

- 关闭启动广告，移除当前 APK 中的广告与同意管理 SDK。
- 首次打开保留简短使用引导；之后直接进入首页，没有广告加载等待。
- 设置页保留「隐私说明」，移除当前不适用的广告隐私入口。
- 保留离线图鉴、中英文、点击本地识别、六只/两只浮窗、双指缩放和双打热门招式 Top 4。

开启悬浮窗 → 返回横屏游戏 → 画面停稳后点「识别」→ 按系统提示授权。开战、换人或形态变化后，请重新识别。

识别目前按三种中文横屏布局适配；英文游戏画面和更多手机仍待验证。弱点按基础属性计算，不包括特性、道具和场地；热门四招是使用率参考，不代表当前对手的真实配招。本包仍为测试签名的早期试用版。

## English

Download **`pokemon-companion-0.7.1.apk`** for Android 8.0+. This version removes startup ads and excludes the advertising and consent SDKs. The first-use guide remains; later launches open the main screen directly. The settings menu now shows the applicable privacy notice without ad controls.

Offline lookups, English/Chinese UI, local tap-to-scan recognition, six- and two-opponent overlays, pinch resizing and popular doubles moves remain available. Recognition is calibrated for three Chinese landscape layouts; English game screenshots and more devices still need testing. Popular moves are statistics, not a confirmed opponent moveset.

The APK uses the same certificate as 0.7.0 with an increased version code, allowing an in-place update. It is an early trial signed with the existing prototype certificate, not a store-reviewed production release.
